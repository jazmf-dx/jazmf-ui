# CSS Classes（Django テンプレート用）

**このページが実装の中心です。**

このプラットフォームのアプリは Django + htmx が主体で、React は Islands のみです。
つまり画面上のボタン・入力欄・カードの大半は **React ではなく素の HTML + CSS クラス**です。

- 定義の SSOT: `packages/dx-ui/tokens/theme.css` の `@layer components`
- 運用ルール: `design-system/components.md`

以下の見本はすべて **Storybook が実アプリと同じ `theme.css` を読んで描画**しています。
コードブロックはそのまま `.html` にコピーできます。

<DoDont
  doText={<><Code>{'<button class="btn-primary">保存</button>'}</Code></>}
  dontText={<><Code>{'<button class="px-5 py-2.5 bg-blue-600 text-white rounded-lg">保存</button>'}</Code></>}
/>

ユーティリティを毎回並べると、**同じボタンが 187 箇所で微妙に違う**という状態になります
（実際にそうなった前例があります）。クラスを使えば 1 箇所の修正で全画面に反映されます。

### 注意事項

- `<a>` にボタンの見た目を付ける場合も同じクラスを使えます。
  ただし**遷移なら `<a>`、処理実行なら `<button>`** を使ってください
  （`<a>` は新しいタブで開ける・`<button>` は Enter/Space で発火する、という期待が違います）
- 送信ボタンには `type="submit"`、それ以外には `type="button"` を明示してください。
  省略すると `<form>` 内では submit 扱いになり、意図しない送信が起きます

class IssueForm(forms.ModelForm):
    class Meta:
        widgets = {
            "title": forms.TextInput(attrs={"class": "input-field"}),
            "body": forms.Textarea(attrs={"class": "input-field", "rows": 5}),
            "status": forms.Select(attrs={"class": "input-field"}),
        }

## CSS クラスと React の対応

同じ見た目が両方に用意されています。**`.html` を書いているなら左、`.tsx` なら右**です。

    ['（テーブルの HTML）', <Code>{'<DxTable>'}</Code>],
    [<Code>badge</Code>, '（React 版なし。span に直接クラスを当てる）'],

  ]}
/>

**CSS クラスを使うためだけに React Island を新設しないでください。**
逆に、React Island の中で `class="btn-primary"` を直書きしないでください
（`DxButton` の状態管理・アクセシビリティ対応が失われます）。

## ダークモードの現状

**この一覧の CSS クラスはダークモードに未対応です。**

`card` / `input-field` は `bg-white`、`form_field.html` は `text-gray-700` を
直書きしているため、ツールバーの Theme を dark にすると破綻します。

これは既知の未対応項目です（対応は別タスク）。
ただし**新しく書くテンプレートでは `bg-white` を増やさない**でください。
